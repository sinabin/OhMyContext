# 프로젝트 라이선스 결정 상태

이 문서는 법률 자문이 아니라 현재 결정 상태와 출시 경계를 기록한다.

## 현재 상태

- 프로젝트는 향후 오픈소스로 공개할 계획이다.
- 구체적인 라이선스와 라이선스 계열은 아직 선택하거나 후보로 좁히지 않았다.
- 무료 EXE 배포와 소스코드의 사용·수정·재배포 권한은 서로 다른 결정이다.
- 최상위 `LICENSE` 파일이 추가되고 공개 승인이 기록되기 전에는 공개 바이너리
  배포와 외부 기여 수락을 진행하지 않는다.

## 나중에 결정할 기준

공개 전에는 최소한 다음을 함께 검토한다.

- 개인 사용, 수정, 재배포, 상업적 이용에 허용할 범위
- 수정본과 네트워크 서비스의 소스 공개 의무를 둘지 여부
- 특허 조항과 상표·브랜드 사용 경계
- 데스크톱 앱, 코어, 커넥터 SDK, 향후 관리형 서비스의 라이선스 경계
- 포함되는 모든 의존성·네이티브 바이너리와의 호환성
- 외부 기여자의 저작권과 기여 동의 운영 방식

이 기준은 후보 목록이 아니다. 실제 선택은 공개 준비 시점의 제품 구조,
배포 방식, 의존성 증거와 필요한 법률 검토를 바탕으로 별도 기록한다.

## 현재 개발에 미치는 영향

로컬 개발, 테스트, 비공개·비민감 fixture용 unsigned 패키징은 계속할 수
있다. 다만 이 활동은 오픈소스 권한 부여나 공개 배포 승인을 뜻하지 않는다.
