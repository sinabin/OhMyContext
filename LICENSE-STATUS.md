# License status

No open-source license has been selected yet.

The project intends to become open source, but the maintainer has explicitly
deferred both the decision and any narrowing of candidates.

Until a `LICENSE` file is committed:

- the code is not offered under an open-source license;
- public binary releases must not be published;
- external contributions must not be accepted or merged;
- copying, modification, and redistribution rights are not granted beyond applicable law.

This hold avoids silently making an irreversible licensing decision. The decision must be completed before the first public release or external contribution.

The repository may generate draft SBOM, checksum, and third-party-notice
evidence for engineering validation. Such tooling and any output marked
`DRAFT — NOT FOR PUBLIC RELEASE` do not select a license or lift this hold.
