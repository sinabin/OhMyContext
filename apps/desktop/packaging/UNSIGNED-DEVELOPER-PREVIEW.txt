OhMyContext Windows Portable ZIP — UNSIGNED

This artifact is the intentionally unsigned Windows x64 Portable ZIP
distribution. Extract the ZIP and run OhMyContextDeveloperPreview.exe. Windows
may display an Unknown Publisher or SmartScreen warning. Use non-sensitive
evaluation data only.

excerpts can leave the computer when an AI client sends them to a cloud model.

published SHA-256 sidecar before running it.
